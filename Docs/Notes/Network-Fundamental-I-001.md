# Learning Notes

## 1. Network Sizes

Networks are designed according to the number of users and devices they support.

### SOHO (Small Office/Home Office)

- Home users
- Small businesses
- Limited devices
- Easier management

### Medium to Large Networks

- Hundreds or thousands of users
- Multiple departments
- Higher security requirements
- More complex infrastructure

---

## 2. Data Transmission

Data moves across a network using different transmission media.

### Electrical Signals

Data is transmitted as electrical pulses through copper cables.

Examples:
- Ethernet Cable
- Twisted Pair Cable

---

### Optical Signals

Electrical signals are converted into light pulses and transmitted through fibre-optic cables.

Advantages:

- Faster
- Longer distance
- Less interference

---

### Wireless Signals

Wireless communication uses electromagnetic waves.

Examples:

- Radio Waves
- Microwaves
- Infrared

---

# Key Concept

The transmission medium determines how data travels.

---

## 3. Bandwidth

Bandwidth is the **maximum capacity** of a network connection to carry data.

Example:

100 Mbps means the network can carry up to 100 megabits every second.

---

## 4. Throughput

Throughput is the **actual amount of data successfully transferred** over a given period.

Throughput is usually lower than bandwidth because of:

- Congestion
- Hardware limitations
- Errors
- Network overhead

---

## 5. Latency

Latency is the delay experienced while data travels from one device to another.

High latency causes slow responses.

Example:

Online gaming and video calls are very sensitive to latency.

---

# Key Difference

| Concept | Meaning |
|----------|---------|
| Bandwidth | Maximum capacity |
| Throughput | Actual transfer speed |
| Latency | Delay in transmission |

---

## 6. Hosts and Servers

Every device connected to a network is called a host.

A computer becomes a server or client depending on the software installed.

Examples:

Server:
- Email Server
- Web Server
- File Server

Client:

- Email Application
- Browser
- FTP Client

---

## 7. Peer-to-Peer (P2P)

In a Peer-to-Peer network, every computer can function as both:

- Client
- Server

Suitable for:

- Home networks
- Small offices
- File sharing

---

## 8. Network Infrastructure

Network infrastructure consists of three major components.

### End Devices

Examples:

- PC
- Laptop
- Phone
- Printer
- Tablet

---

### Intermediary Devices

Examples:

- Router
- Switch
- Firewall
- Wireless Access Point

Purpose:

Directs and manages network traffic.

---

### Network Media

Examples:

- Copper cable
- Fibre-optic cable
- Wireless communication

---

## 9. Internet Service Provider (ISP)

An ISP provides Internet connectivity.

Common connection methods include:

### Cable Internet

- Uses coaxial cables.
- Often shared with television services.

### DSL (Digital Subscriber Line)

- Uses telephone lines.
- Always-on broadband connection.

---

## 10. Wireless Technologies

### Wi-Fi

Wireless local network technology.

---

### Bluetooth

Short-range communication.

---

### NFC

Near Field Communication.

Used for:

- Contactless payments
- Device pairing

---

### GPS

Global Positioning System.

Uses satellites for positioning and navigation.

---

## 11. SSID

SSID stands for:

**Service Set Identifier**

It is the visible name assigned to a Wi-Fi network.

Example:

Freedom_Home_WiFi

---

# Important Takeaways

- Network size determines infrastructure complexity.
- Data can travel through electrical, optical, or wireless media.
- Bandwidth is different from throughput.
- Latency measures communication delay.
- Hosts become servers depending on installed services.
- Peer-to-Peer networks eliminate the need for a dedicated server.
- Network infrastructure includes end devices, intermediary devices, and media.
- ISPs provide Internet connectivity.
- Wi-Fi networks are identified using an SSID.

---

# Corrections Made During Review

- LAN and WAN are network types, not transmission media.
- Bandwidth refers to maximum capacity, not actual speed.
- Throughput is the actual data successfully transferred.
- An ISP connects users to the Internet rather than simply connecting two computers.
